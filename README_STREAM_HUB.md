# CassXP — Stream Hub

Novo site responsivo com página Início, Lives, Clipes, Jogos, Jade Devonne e Conheça Cass.

Preserva o MP3 e a verificação de Google Search Console já publicados na raiz do repositório; o arquivo de música não é incluído neste pacote.

O player da Twitch usa a API oficial de incorporação. Reprodução automática com áudio depende das regras do navegador.

Nova página **Conheça Cass** criada com a apresentação fornecida pelo proprietário do canal.
